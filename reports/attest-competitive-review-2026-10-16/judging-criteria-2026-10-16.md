# Official judging criteria and submission requirements, re-verified 16 Oct 2026 17:24 UTC

Source: `https://nebiusglobalaihackathon.devpost.com/` (overview), `/rules`, `/project-gallery`, fetched with curl and a
Chrome user agent (Devpost returns 403 to automated fetchers without one). Text below is quoted or closely paraphrased.

## Two-stage judging

Stage One: minimum requirements and track fit ("a genuine attempt at the track's stated goal, not a superficial
rebrand of an unrelated idea"). Stage Two: four **equally weighted** criteria, at the judges' sole discretion:

1. **Technological Implementation.** "How well is the project built, and how effectively does it use Nebius Token
   Factory or AI Cloud model(s), and NVIDIA Nemotron or other NVIDIA open source models as part of the solution?"
2. **Design.** "Does the project deliver a complete, coherent product experience not just a technical proof of concept?"
3. **Potential Impact.** "Does the project make a credible, specific case for solving a real problem for a real
   audience and does the solution actually address it based on what's demonstrated?"
4. **Quality of the Idea.** "Is this a creative, non-obvious use of Nebius Token Factory or AI Cloud model(s), and
   NVIDIA Nemotron and does the team show genuine understanding of the problem space?"

Tie breaking: the tied submission with the highest score in the first applicable criterion listed above wins; repeated
down the list. Technological Implementation is therefore the first tie-breaker.

## Track requirement

Coding and Agentic Engineering Track: "Build coding agents and developer tools: agents that write, run, and test code
in Token Factory." All submissions must run on Nebius Token Factory or Nebius AI Cloud and use at least one NVIDIA open
source model.

## What to submit

- A working project that meets the track requirements; a category.
- A project description: what, why, how.
- A working demo URL (hosted application or test build).
- A demo video, 3 minutes or shorter, public on YouTube, showing the project working and how Token Factory and
  Nemotron were used; judges are not required to watch beyond three minutes; no third-party trademarks or copyrighted
  music.
- A public code repository (GitHub, GitLab or Bitbucket) with an open source license (Apache 2.0, MIT or MPL 2.0)
  visible at the top of the repository page, and a README with setup instructions, clear guidance for running the
  project, and a highlight of how Nemotron was used, where Token Factory accelerated the workflow, and any other
  Nebius tools or services used.
- Feedback on Token Factory, AI Cloud and the NVIDIA tools used (a separate feedback submission is eligible for a
  feedback prize, judged on completeness, viability and potential impact).
- If the project existed before the submission period, a written explanation of what was significantly updated.
