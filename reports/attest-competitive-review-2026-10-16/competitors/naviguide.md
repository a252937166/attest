### User and problem served
Crew and followers of the team's own Berry-Mappemonde catamaran expedition and "virtual sailors": a map-first briefing of what matters near the boat (EEZ borders, official ports of entry, protected areas, wind/sea state, next harbour), a logbook chat, port-of-call sheets, plan review and a narrated replay film, under the rule "Unknown field = empty. ### Complete workflow a user can actually perform today
Entry points: React/Vite SPA at simulator.naviguide.fr; FastAPI server `naviguide-simulator/server/main.py` plus routers (`voyage_api.py`, `escale_api.py`, `logbook_chat.py`, `polar_api.py`, `bi_proxy.py`) exposing `GET /ici`, `POST /ici/story`, `GET /ici/warm/status`, `GET /voyage/official/{clock,journal,moments,film,plan-review,advice}`, `POST /voyage` and `GET /voyage/{id}/…`, `POST /logbook/chat`, `GET /escale`, weather/EEZ proxies, admin-only writes (`X-Naviguide-Admin`); local run `cd naviguide-simulator && bash dev-mac.sh` (keys outside the repo; without keys "the story falls back to rules"). Users can follow the official expedition, play the narrated film in "Raw" (rules text) or "Edited" (Nemotron Super) style, read Now/Story/Log/Plan-review panels, ask the logbook chat, open port-of-call sheets, draw/import a route and get the same briefing, export GeoJSON/KML. Blue Intelligence (`backend/`, `frontend/`, MongoDB) returned 502 at all three probes, so it was not inspected.

Cost pattern, as implemented:
- `server/llm_budget.py`: `NAVIGUIDE_LLM_MODE` defaults to `on-demand` ("only on a user action — chat question, click « Rédigé » — never in background"). Background work runs under `llm_budget.background()`, where `allow()` is False and the cascade returns `source="budget"` with no network call; one exception, `deferred_demand()`, lets the stock worker pre-write the film's "written" plan. Daily token caps (defaults): fast 200k (Lightning), write 150k (Super), deep 80k, judge 60k (Ultra); chat-Ultra ≤10 calls/day; Tavily 80 credits/day; counters in SQLite kv `llm-budget:<date>:<tier>` with USD from a hard-coded price grid; `status()` is served at `GET /ici/warm/status`.
- `server/story_cascade.py` `cascade_text`: SQLite prompt cache (24 h) → Token Factory (model per tier) → NVIDIA NIM `gpt-oss-20b` → OpenRouter `gpt-4o-mini` → Claude Haiku 4.5 → rules; in-flight dedupe; 4 parallel TF calls; 25 s/45 s timeouts; `filter_numbers` drops any sentence containing a number absent from the facts.
- `server/story_cache.py`: `POST /ici/story` reads the `story` cache (7-day TTL) first; 300 stories/day; "no more background pre-generation (RG18): a story is only written on the Rédigé pill". Rate limits: 12 stories/min/IP, 60/min, 240/h global.
- Client `src/engine/storyQueue.js`: `shouldEnqueueStory(ev,{written})` is false unless `written` ("RG18: never by itself — only the Brut/Rédigé switch (written) buys Super"); fire-and-forget; 429 → "failed" → local phrase. (Its header still says "Not Nemotron. Not Token Factory" — stale.)
- Film: `GET /voyage/official/film?style=raw|written` is served from the precomputed stock ("never a computation on the request", `official_store.serve_film`); `hasWritten` is true only when the worker's `fill_written_film()` already produced that (lang, seconds) variant. `src/hooks/useReplay.js` probes `style=written`, enables the "Edited" pill only when `hasWritten` (`writtenPillEnabled`), otherwise shows "not yet written for this duration"; `SimulationFilmBar.jsx` holds the toggle and a `film-source` label shown only for written text.
- Indicators: `src/utils/llmSourceLabel.js` + i18n render "Nemotron 3 Super · Token Factory", "Nemotron 3 Ultra · Token Factory", "rules", "budget", "cache", "NVIDIA NIM (fallback)" with brand logos for Nemotron. No user-facing remaining-budget meter was found; counters exist only on the status endpoint.
- Chat (`logbook_chat.py`): Lightning parses intent, rules answer from the fact packet (`source=rules`), Ultra only on an explicit "Reason" gesture under `allow_chat_ultra()`.
- Live evidence (`GET /ici/warm/status`, 17:45 UTC, HTTP 200): today fast 12 calls/10,541 tokens/$0.00088; write 219 calls/142,893 tokens/$0.059 (default cap 150k; production cap unknown); deep 5 calls/26,770 tokens/$0.027; judge 0; Tavily 8 credits; chatUltra 0/10; `lastSource: "nemotron-super"`; `lastError: tokenfactory "tokenfactory empty"`; store stories 124, filmStory 171, watch 22, truth 0; `"stories":{"skipped":"on-demand"}`.

### Verification method, trust boundaries, failure handling
No ground-truth check of narrative quality; "correctness" means numeric fidelity: `filter_numbers`, `film_script.apply_written_guard` (a written sentence replaces the raw one only if its numbers and place names are subsets of the facts, else the raw sentence is kept), `tidy_story` caps, prompt-leak/think-block stripping. No code execution anywhere; all LLM calls are server-side httpx requests to Token Factory (`api.tokenfactory.nebius.com/v1`; Ultra via `us-central1`), with NIM/OpenRouter/Anthropic fallbacks and Tavily; hosting is an Ubuntu VPS (nginx → uvicorn, SQLite store 3.49 GB per live status). No Nebius Sandboxes/Jobs. Trusted: server-held keys, admin header for writes, per-IP rate limits (admin exempt), CORS list. Failures: provider error → next provider → rules text, always labelled; cap reached → `source=budget`, no network; stock miss → "preparing" payload and `kick_worker()`; story 429 → client shows the local phrase; chat `status: failed` only if even the fact template is impossible; `NAVIGUIDE_OFFLINE=1` mode. Observed: API 502 behind nginx at 17:41 UTC, back at 17:45 UTC with `startedAt` 17:45:00 (restart; PR #516 "sync nginx … au déploiement" opened 17:37 UTC).
