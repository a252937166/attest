Repairs of the core findings of `reports/attest-audit-2026-10-19/core-findings.md`. Every item below names the files, the
mechanism, the acceptance tests (all in `tests/test_audit_core.py` unless stated) and what remains a limitation. The

Also repaired here: the contract audit now records only conflicts that name existing acceptance criteria, executes their
witnesses only then, and counts a witness as a demonstration only when its marker line names at least one of the claimed
requirements (`WitnessValidation`); the rule text states that an executed witness is a model claim with a recorded
execution, not a formal proof of impossibility. The arbitration record of a refused arbitration (`not attempted`) carries
the full key set so that the harness and the exhibits render it.
